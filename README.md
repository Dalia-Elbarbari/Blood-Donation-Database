# Blood Donation Relational Database System

A relational database project designed to support the management of blood donation operations, including donor records, laboratory testing information, blood inventory tracking, and distribution processes. The system was developed with a strong focus on database design principles, data integrity, and efficient information retrieval.

The database architecture was modeled using Enhanced Entity-Relationship Diagrams (EERD) to represent relationships between donors, blood units, laboratory tests, and distribution channels. Primary and foreign key constraints were implemented to maintain referential integrity and ensure consistency across interconnected data structures.

Normalization techniques were applied throughout the schema design process to reduce redundancy, improve data organization, and support reliable database operations. Particular attention was given to designing structured relationships capable of accurately representing real-world blood bank workflows.

The project also involved the development of SQL queries for data retrieval, reporting, and analytical purposes. Query operations incorporated joins, subqueries, aggregations, and conditional filtering techniques to extract meaningful insights from stored data and support inventory monitoring activities.
